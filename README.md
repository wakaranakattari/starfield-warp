# starfield-warp

Terminal warp-speed starfield built with [ratatui](https://github.com/ratatui/ratatui).
Sibling of `matrix-rain`: same loop, new physics.

```
cargo run --release
```

| Key                       | Action            |
| ------------------------- | ----------------- |
| `Space`                   | Toggle warp boost |
| `Up` / `Down` / `+` / `-` | Speed             |
| `Tab` / `Shift+Tab`       | Next / prev theme |
| `p`                       | Pause             |
| `h`                       | Toggle HUD        |
| `q` / `Esc`               | Quit              |

## Themes

`Starlight` → `Matrix` → `Nebula` → `Solar` → `Ice` → `Crimson` → `Sunset` → `Ghost`
